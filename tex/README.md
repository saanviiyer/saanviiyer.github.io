# Editable .tex sources

Parallel LaTeX sources for the research blog posts and project pages, for editing in VS Code.

- posts/   one .tex per research blog post (from _posts/*.md)
- projects/  one .tex per research project page (from pages/proj-*.html)

These are a convenience copy. The live site still renders from the .md and .html files,
so a change here does not publish until it is carried back into the matching .md or .html.
This folder is excluded from the Jekyll build.
