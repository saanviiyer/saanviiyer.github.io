Perceive

World models that keep a stable picture of physical reality

I'm excited about world models and about building more aligned simulations of physical reality, for applications in robotics and scientific reasoning. The world doesn't operate through language. It follows physical laws and constructs, and models that can understand them are better equipped to address the world's critical needs. Perceive is three small labs that run in the browser. Each one asks whether a model holds a stable, physically faithful picture of its world, using measurements borrowed from neuroscience.

Generated worlds: what this is

A simulated 3D room is rendered twice along the same camera path. One render comes from a ground-truth simulator. The other comes from a stand-in world model that predicts the room from the agent's actions alone and forgets objects that stay out of view too long. The audit reads only the rendered frames and reports how long the model's picture of the room stays consistent, using the place-field analyses used to study the hippocampus. The stand-in model is synthetic and its failures are planted on purpose, so this lab tests the measurement itself. It has not yet been run on a real video world model.

Why I looked at it

A robot trained inside a generated world needs that world to still be there when it turns around. Frame-quality scores do not check this, because they judge short clips and never ask about the return trip. From neurobiology, the standard test for whether an animal holds a stable map is whether its place cells keep the same firing fields when it comes back to an unchanged room. I wanted to see whether the same test gives a useful number for generated environments.

How it works

The world model here is a controlled stand-in. It re-imagines objects that stay out of view past the memory limit, and its camera drifts. Planting known failures shows whether the audit catches them before it is pointed at a real checkpoint.

View cells. Frames are downsampled to 24×18 colour pixels. 64 units each respond to one reference view, exp(−(1−cos)/τ). One bank reads both sources.

Spatial information. Skaggs bits over a 10×10 room grid, against 40 circular shifts of each activity trace.

Remapping. Split-half rate-map correlation, scaled between the simulator (0) and a shuffle null (1). The room never changes, so any change is spurious.

Memory horizon. Revisit pairs within 30 cm and 13°, binned by gap and normalised by the simulator's own fall-off.

RoBoWoMo

A heading variable that a world model builds on its own

What this is

Three of the world models from my RoBoWoMo study, loaded from their trained checkpoints and running live in the browser. Each is a small recurrent network (a GRU with 128 units) trained only to predict a robot's next range-sensor reading in a 2.2 by 1.4 m arena. None of them is ever given the robot's heading. The three differ only in training: observations withheld in stretches (blackout), always observed, or blackout with the action stream scrambled in time (a control that cannot integrate motion). You can black out the sensors and watch whether each network keeps track of which way the robot faces.

Why I looked at it

Head-direction cells in the rodent brain keep a sense of heading in the dark by integrating self-motion. I wanted to know whether a predictive world model builds a comparable variable without being told to, and how to tell a real one from structure that only looks like one. A ring-shaped cloud of hidden states appears even in controls that cannot integrate, so the study measures how faithfully the ring tracks true heading where the model has to integrate.

Abstract, RoBoWoMo workshop at IEEE IROS 2026

A world model is a recurrent model trained to predict its own next observation, and to predict well when the world is partly hidden it has to hold an internal state. The interesting question is what that state becomes. If it becomes a clean variable that lines up with something concrete, like which way the agent is facing, you can read it, trust it, and steer it. If it stays a tangle, the model can still predict while carrying nothing you can use. I train action-conditioned world models on a robot's range sensors with no access to its heading, and a steerable heading variable appears only under partial observability: the lowest-fidelity blackout model tracks true heading at a ring-coordinate fidelity of 0.860 while the best control reaches only 0.613, so the two groups separate with no overlap, and the variable behaves like a continuous attractor that is steered causally. A companion study pushes the same question further, showing that a probe can read a coordinate out of the latent state that the dynamics set aside, and that the coordinates the dynamics do use are set by what the observation makes separable, not by the number of actuators.

How it works

Blackout training withheld observations for stretches, forcing the model to integrate its actions. Always observed never withheld anything. Shuffled actions had the same blackouts, but its actions were scrambled in time, so it is the matched null.

Try: hold B on the blackout model, then on the shuffled one. Both have ring-shaped state clouds; only one keeps the dot moving with the robot in the dark.

The heading readout is a linear map fit after training, only to score the models. It is fit on all states, so the controls score worse here than with the paper's deep-blackout readout. Over 2,000 headless test-regime steps this page gives 2.1°, 23.1° and 40.1°; the paper reports 1.8°, 16.2° and 22.8°.

The ring plane is PCA of states near the arena centre, so it reflects heading rather than position. The JS GRU matches the PyTorch checkpoints to within 0.002.

Fly compass

The fruit fly's heading circuit as a world model you can take apart

What this is

A simulation of the fruit fly's head-direction circuit: a ring of 32 model neurons holding one bump of activity that marks the fly's heading. The four cell types and the direction of their connections follow the central-complex wiring mapped in the fly connectome. The weights are simplified and are not real synapse counts. Each run covers 15 s of light, 30 s of darkness and 15 s of light. You can cut any pathway and see how heading tracking fails, and a lesion table compares every cut on the same fly.

Why I looked at it

The fly's circuit is a small, fully mapped example of what an action-conditioned world model has to do: predict from self-motion when it cannot see, and correct from vision when it can. Cutting one pathway at a time gives a distinct failure signature for each part. I wanted those signatures as a reference for diagnosing which part of a learned world model has broken.

How it works

The fly tracks heading with one bump of activity on a ring of E-PG neurons. P-EN neurons shift the bump as the fly turns; ring neurons pin it to what the fly sees; Δ7 inhibition keeps a single bump; recurrence holds it in the dark.

That is the predict-and-correct loop of an action-conditioned world model: P-EN ≈ transition, ring neurons ≈ observation update, recurrence ≈ memory, Δ7 ≈ competition between hypotheses.

The model follows the hemibrain connectome's topology, not its synapse counts. Weights are idealised: a cosine ring, an angular-velocity-gated shift and inhibitory landmark input. The bump-to-world offset is estimated label-free from the lit epoch, as it must be in the fly.

About Perceive

Does a world model keep a stable map?

I'm excited about world models and about building more aligned simulations of physical reality, for robotics and scientific reasoning. A robot can only learn inside a generated world if that world is still the same world when the robot turns around. These labs test that with tools from neuroscience: place-cell remapping for generated 3D rooms, heading-ring fidelity for my own trained world models, and pathway lesions in the fly's head-direction circuit.

Saanvi S. Subramanian, October 2026

From video to an environment you can walk back into

A video world model can look photoreal frame by frame and still be unusable as an environment. Frame metrics such as FVD score short clips and never ask about the return trip. The generated-worlds audit extends to real posed video:

  1. Poses from the action stream, or structure-from-motion for raw video.
  2. Revisit graph of frame pairs close in pose and far apart in time.
  3. Features from a frozen self-supervised encoder in place of pixels.
  4. Audit: memory horizon, remapping and per-region stability, each with a null.
  5. Build: fuse only consistent regions into 3D (e.g. Gaussian splats); re-anchor the rest.

Next experiments

  1. Run the audit on real checkpoints and report memory horizon next to FVD.
  2. Validate it: train one navigation policy inside rollouts from checkpoints with different horizons and test transfer to the reference simulator. The audit is only useful if horizon predicts transfer, and that test can fail.
  3. Ablate a learned model's action, observation and memory pathways and match its rollouts against the fly-compass lesion atlas.
  4. Test pose-indexed memory against plain longer context at matched compute.

Prior work this builds on

RoBoWoMoIEEE IROS 2026 workshop, poster and lightning talk

Blackout training makes a faithful heading ring emerge in action-conditioned world models with no pose supervision: 0.860 fidelity for the lowest blackout model against 0.613 for the best control, across 36 models with no overlap. Runs live in the RoBoWoMo tab.

Scaffold WMin progress

A small world model joined to a hippocampus-style memory, after the spatial-scaffold account of Chandra, Sharma, Chaudhuri and Fiete (Nature 2025). It targets the forgetting the generated-worlds audit measures.

NeuroDev WMin progress

What fixes the order in which world-model capabilities emerge, compared with rodent head-direction development. Appearance arrives near step 8, the heading coordinate between steps 63 and 106.

CortSeerECCV & NeurIPS 2026 workshop orals

Routing clinical brain-lesion decisions on self-agreement instead of confidence: 88.4% against 70.0% accuracy at 40% coverage. The generated-worlds audit applies the same idea: agreement with itself at a revisit beats how good one frame looks.

Neuro-VLA IBpilot

Ring and grid latents in language-conditioned world models. The pilot came back negative and was reported that way: a neural analogy has to beat its control.

Built with three.js r128, the RoBoWoMo GRU checkpoints (float16) and a 32-unit ring attractor. Everything runs in the browser.
