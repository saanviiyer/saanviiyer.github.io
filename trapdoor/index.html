A hands-on cryptography lab. Every number on this page is computed live in your browser, from scratch, with BigInt.

Teaching code only. These are textbook algorithms written by hand, with tiny numbers, no padding and no protection against timing or other side-channel attacks. Real systems must use audited, well-maintained libraries. Never ship hand-rolled cryptography.

All math is implemented in this page with JavaScript BigInt: trial division, Euclid, square-and-multiply, AES, SHA-256 and the rest. No cryptography library is used, which is the point. Random numbers come from the browser's crypto.getRandomValues.

For anything real, use an audited library such as libsodium or your platform's vetted cryptographic API.
