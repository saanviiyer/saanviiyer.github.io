Evaluating protein-design agents

Saanvi S. Subramanian, poster, AgenticLS @ NeurIPS 2026 and AI for Science @ NeurIPS 2026

A protein-design agent ranks thousands of candidates with a learned scorer, trusts that scorer because a benchmark reported a correlation, and keeps a proposal only if a verifier clears it. This page tests three of those components where measured ground truth exists.

  • Scorer resolution
  • Verifier
  • In-silico vs measured

The scorer compresses 78 distinct actions into one region

Action identifiability, AgenticLS @ NeurIPS 2026

An agent can only choose between actions its scorer keeps apart. Using the 78 COSMIC single-base-substitution signatures as a controlled action space, each action is executed on a coding sequence, embedded with ESM-2, and scored by distance to a target Pfam-domain centroid. Across 3,003 signature pairs, median pairwise distance falls from 0.815 in COSMIC spectrum space to 0.0068 between ESM-2 outcome regions, a 120x compression, and a composition-matched control reproduces the destinations.

A learned policy trained to name which of the 78 signatures produced a given embedding shift reaches 7.55% top-1 accuracy on a protein-grouped split, against 1.28% for uniform chance and 6.12% for a nearest-neighbor baseline. Split-conformal prediction reaches 92.2% coverage only by returning 66.8 of 78 actions on average. The scorer carries a real signal and still cannot single out a specific action.

A trust gate certifies a scorer that memorized the answers

Verifier red-teaming

A closed-loop agent delegates ranking to a supplied scorer only if a trust gate clears it, and the gate scores the scorer on outcomes collected so far. Across 4,920 trials, a scorer that memorizes the observed outcomes clears the gate at AUROC 0.991 and passes every trial, against 0.663 for a truthful scorer worth +1.082. Forward validation closes that surface, and a pool-side attacker that touches only unmeasured candidates still returns identical gate statistics by construction and costs 1.24 good candidates per batch.

A probe that spot-checks the scorer's own top picks catches 99.2% of naive attacks yet recovers about 10% of the lost value with a random fallback, because catching an attack and replacing it are different problems. Recovery needs a second source of capability outside the compromised scorer, a model trained on the campaign's own measurements.

The in-silico proxy ranks below counting mutations

Gauntlet, AI for Science @ NeurIPS 2026

Before an agent ranks designs with a proxy, the proxy has to beat a trivial baseline on measured outcomes. On 504 measured PET-hydrolase variants across 25 studies, a zero-shot ESM-2 650M score ranks activity at a within-study Spearman of 0.01, below a hydropathy feature and well below a plain mutation count at 0.25. On the property a campaign would use it for, the expensive model is the weakest of four scorers.

What the three share

Each component is a measurement read off a static corpus, and each stops meaning what it claims once an optimizer selects on it. A scorer that cannot resolve the actions, a gate scored in sample, and a proxy that loses to counting all pass their headline check and fail where the agent uses them.
