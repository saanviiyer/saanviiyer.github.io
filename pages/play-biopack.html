BioPack

I built BioPack as a forward-only workspace for protein structure and stability on a small panel of well-characterised benign proteins. You give it a protein and one mutation, and it returns a stability estimate or a refusal. A refusal names the first place where the query falls outside what the panel and the calibration data support. I left out sequence design and any optimisation loop on purpose.

This is a demo. The structures below are real deposited PDB coordinates for the panel proteins. Every model output on this page is a synthetic placeholder that your browser generates for illustration, and that includes all three analysis panels. None of it is a real prediction or biological evidence.

I see the six refusal reasons as the real contribution of BioPack. BioPack answers a query only after the query clears every gate. When a query fails, the refusal names the first gate it fails.

  • off panel means the accession is not one of the panel proteins.
  • position out of range means the mutation position exceeds the sequence length.
  • wildtype mismatch means the stated wild-type residue does not match the parent sequence.
  • no calibration means the query lies outside the region with reference data.
  • below noise floor means the effect in question is smaller than the assay floor.
  • model unavailable means BioPack could not reach the backend.

This page runs entirely in your browser on GitHub Pages. The live research version needs a Python backend to run the real stability models and the calibration arm. The repository at github.com/saanviiyer/biopack holds the forward-only API and the gates, along with the frozen benign panel. The wild-type, calibration, noise-floor and model-backend checks run only in that repository, so this static demo skips them.
